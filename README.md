# YtdlpCLI

## How to use

1. Release ZIP を展開します。
2. `tools\ffmpeg.exe` を配置します。
3. `YtdlpCLI.exe` を起動し、URL と保存先を入力します。

yt-dlp は Release に同梱されています。`tools\yt-dlp.exe` がない場合も、起動時に yt-dlp 公式の最新版を自動ダウンロードします。

動画の結合・音声抽出には ffmpeg が必要です。ffmpeg の実行ファイルは [gyan.dev](https://www.gyan.dev/ffmpeg/builds/) などから取得して、`tools\ffmpeg.exe` に置いてください。
